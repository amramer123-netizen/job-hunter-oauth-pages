Privacy Policy

Effective date: October 19, 2026

This policy describes how AI Universe Job Hunter, a locally operated personal job-search application, uses data when its owner connects a Google account. It is intended to describe the local application, not GitHub's separate handling of visits to this public information website.

Data accessed

With the account holder's authorization, the application requests the Gmail gmail.readonly and gmail.send scopes. These allow it to read Gmail messages and metadata relevant to the configured workflows and to send messages only when sending functions are explicitly enabled and used. The app also receives OAuth tokens required to maintain authorized access.

Purpose and use

Gmail data is used for user-directed job-search workflows, including identifying job-related correspondence, managing follow-up information, and supporting approved outgoing messages. The application is not presented as a public email service or advertising platform.

Storage and security

The application runs locally, backed by a database under the owner's control. Google OAuth credentials are stored encrypted in that database. Job-search records and any email-derived data may also be stored locally as required for application features. No Gmail credentials, messages, or local database contents are published in this GitHub Pages website.

Sharing

The operator does not sell Gmail data or use it for advertising. Data is not intentionally shared with unrelated third parties. When the operator chooses to use other services as part of a workflow (such as an AI service or a destination for an outgoing message), information may be transmitted to those services as needed for that specific action, subject to their own terms and policies. Any such integrations should be reviewed before use.

Retention and deletion

Application records are retained in the locally controlled database until the operator deletes them or removes the application's stored data. Google access can be revoked at any time from the Google Account third-party connections settings. Revocation prevents further authorized Gmail access but does not itself delete previously stored local records.

Google API Services User Data

Use of information received from Google APIs is intended to comply with the Google API Services User Data Policy, including its Limited Use requirements. Google user data is used only for the user-facing Gmail functionality described above.

Changes

This notice may be updated when the application's actual data practices change. The effective date above will be updated accordingly.
